# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

### Данные
В приложении используются две основные сущности данных: товар и покупатель.

#### Интерфейс IProduct
Интерфейс описывает товар, который отображается в каталоге, может быть открыт для подробного просмотра и добавлен в корзину.

Поля интерфейса:  
`id: string` - уникальный идентификатор товара. Используется для поиска товара, проверки его наличия в корзине и удаления товара.  
`title: string` - название товара.  
`image: string` - ссылка на изображение товара.  
`category: string` - категория товара.  
`price: number | null` - стоимость товара. Если значение равно null, цена товара не указана.  
`description: string` - описание товара, которое отображается при подробном просмотре.  

#### Тип TPayment
Описывает доступные способы оплаты.

`TPayment = 'card' | 'cash'` - тип способа оплаты. Значение `card` означает оплату онлайн, `cash` - оплату при получении.

#### Интерфейс IBuyer
Интерфейс описывает данные покупателя, которые нужны для оформления заказа.

Поля интерфейса:  
`payment: TPayment | ''` - выбранный способ оплаты. Пустая строка означает, что способ оплаты ещё не выбран.  
`address: string` - адрес доставки.  
`email: string` - электронная почта покупателя.  
`phone: string` - телефон покупателя.  

### Модели данных

#### Класс ProductCatalog
Класс отвечает за хранение и работу с товарами каталога.

Конструктор:  
`constructor(events: IEvents)` - принимает брокер событий.

Поля класса:  
`events: IEvents` - брокер событий, используемый для генерации событий.  
`products: IProduct[]` - массив всех товаров каталога.  
`preview: IProduct | null` - товар, выбранный для подробного отображения. Если товар не выбран, хранится значение null.

Методы класса:  
`setProducts(products: IProduct[]): void` - сохраняет массив товаров, переданный в параметре, в модель.  
`getProducts(): IProduct[]` - получает массив всех товаров.  
`getProductById(id: string): IProduct | undefined` - получает товар по его идентификатору.  
`setPreview(product: IProduct): void` - сохраняет товар для подробного отображения.  
`getPreview(): IProduct | null` - получает товар, выбранный для подробного отображения.  

События:  
`catalog:changed` - генерируется при изменении списка товаров каталога.  
`preview:changed` - генерируется при изменении товара, выбранного для подробного отображения.

#### Класс Basket
Класс отвечает за хранение и работу с товарами, которые пользователь добавил в корзину.

Конструктор:  
`constructor(events: IEvents)` - принимает брокер событий.

Поля класса:  
`events: IEvents` - брокер событий, используемый для генерации событий.  
`items: IProduct[]` - массив товаров, добавленных в корзину.

Методы класса:  
`getItems(): IProduct[]` - получает массив товаров, которые находятся в корзине.  
`addItem(product: IProduct): void` - добавляет товар, переданный в параметре, в корзину.  
`removeItem(product: IProduct): void` - удаляет товар, переданный в параметре, из корзины.  
`clearBasket(): void` - очищает корзину.  
`getTotalPrice(): number` - получает общую стоимость товаров в корзине.  
`getItemsCount(): number` - получает количество товаров в корзине.  
`hasItem(id: string): boolean` - проверяет наличие товара в корзине по его идентификатору.  

События:  
`basket:changed` - генерируется при добавлении, удалении товаров или очистке корзины.

#### Класс Buyer
Класс отвечает за хранение, изменение, очистку и валидацию данных покупателя.

Конструктор:  
`constructor(events: IEvents)` - принимает брокер событий.

Поля класса:  
`events: IEvents` - брокер событий, используемый для генерации событий.  
`payment: TPayment | ''` - выбранный способ оплаты.  
`address: string` - адрес доставки.  
`email: string` - электронная почта покупателя.  
`phone: string` - телефон покупателя.  

Методы класса:  
`setBuyerData(data: Partial<IBuyer>): void` - сохраняет данные покупателя в модель. Позволяет обновить одно или несколько полей, не удаляя остальные сохранённые данные.  
`getBuyerData(): IBuyer` - получает данные покупателя.  
`clearBuyerData(): void` - очищает данные покупателя.  
`validateBuyerData(): IErrorsBuyer` - проверяет данные покупателя и возвращает объект с ошибками. Если ошибок нет, возвращает пустой объект.  

События:  
`buyer:changed` - генерируется при изменении или очистке данных покупателя.

### Слой коммуникации

#### Класс WebLarekApi
Класс отвечает за обмен данными с сервером. Использует экземпляр класса Api, переданный в конструктор, и вызывает его методы get и post.

Конструктор:  
`constructor(api: IApi)` - принимает объект для выполнения запросов к серверу.

Поля класса:  
`api: IApi` - объект, который используется для отправки запросов.

Методы класса:  
`getProducts(): Promise<IProductsResponse>` - выполняет GET-запрос на эндпоинт /product/ и возвращает объект с массивом товаров.  
`sendOrder(order: IOrder): Promise<IOrderResult>` - выполняет POST-запрос на эндпоинт /order/, отправляет данные заказа и возвращает объект с идентификатором заказа и итоговой стоимостью.

### Слой представления

#### Класс Header
Класс отвечает за отображение счётчика товаров в корзине в шапке сайта и генерирует событие при нажатии на кнопку корзины.

Данные:
`counter: number` - количество товаров в корзине, отображаемое в счётчике.

Конструктор:  
`constructor(events: IEvents, container: HTMLElement)` - принимает брокер событий и корневой DOM-элемент шапки сайта.

Поля:
`events: IEvents` - брокер событий, используемый для генерации событий.  
`counterElement: HTMLElement` - DOM-элемент счётчика товаров в корзине.  
`basketButton: HTMLButtonElement` - кнопка открытия корзины.

Сеттеры:  
`counter(value: number)` - устанавливает значение счётчика товаров в корзине.

События:  
`basket:open` - генерируется при нажатии на кнопку корзины.

#### Класс Gallery

Класс Gallery отвечает за отображение готовых карточек товаров в каталоге.

Данные:
`catalog: HTMLElement[]` - массив DOM-элементов карточек товаров.

Конструктор:
`constructor(container: HTMLElement)` - принимает корневой DOM-элемент каталога.

Поля:
Собственных полей нет. Для работы с контейнером используется унаследованное от `Component` поле `container`.

Сеттеры:
`catalog(items: HTMLElement[])` - заменяет содержимое каталога переданными DOM-элементами карточек товаров.

События:
Класс не генерирует событий.

#### Класс Card
Абстрактный базовый класс для компонентов карточек товара. Класс является дженериком и принимает тип `T extends ICard`, что позволяет дочерним классам расширять базовый набор данных карточки. Отвечает за отображение общих для всех видов карточек данных: названия и цены товара. 
  
Данные:  
`ICard` - тип данных карточки, созданный на основе `IProduct` с помощью `Pick` и содержащий поля `title` и `price`.

Конструктор:  
`constructor(container: HTMLElement)` - принимает корневой DOM-элемент карточки товара.

Поля:  
`titleElement: HTMLElement` - DOM-элемент с названием товара.  
`priceElement: HTMLElement` - DOM-элемент с ценой товара.

Сеттеры:  
`title(value: string)` - устанавливает название товара.  
`price(value: number | null)` - устанавливает цену товара. Если цена отсутствует, отображает значение «Бесценно».

События:  
Класс не генерирует событий.

#### Класс CardCatalog

Класс карточки товара в каталоге. Наследуется от класса `Card`. Отвечает за отображение изображения и категории товара и вызывает переданный обработчик при выборе карточки пользователем.

Данные:  
`ICardCatalog` - тип данных карточки каталога, содержащий базовые данные `ICard`, а также поля `image` и `category` из `IProduct`.

Конструктор:  
`constructor(container: HTMLElement, actions: ICardCatalogActions)` - принимает корневой DOM-элемент карточки и объект с обработчиком пользовательского действия.

Поля:  
`imageElement: HTMLImageElement` - DOM-элемент изображения товара.  
`categoryElement: HTMLElement` - DOM-элемент категории товара.

Сеттеры:  
`category(value: string)` - устанавливает название категории и соответствующий ей CSS-класс.  
`image(value: string)` - устанавливает изображение товара.

Обработчики:  
`onClick` - вызывается при нажатии на карточку товара.

#### Класс CardPreview

Класс карточки подробного просмотра товара. Наследуется от класса `Card`. Отвечает за отображение изображения, категории, описания товара и переданного состояния кнопки действия.

Данные:  
`ICardPreview` - тип данных карточки подробного просмотра, содержащий базовые данные `ICard`, поля `image`, `category` и `description` из `IProduct`, а также поля `buttonText` и `buttonDisabled`, определяющие отображение кнопки действия.

Конструктор:  
`constructor(container: HTMLElement, actions: ICardPreviewActions)` - принимает корневой DOM-элемент карточки и объект с обработчиком действия кнопки.

Поля:  
`imageElement: HTMLImageElement` - DOM-элемент изображения товара.  
`categoryElement: HTMLElement` - DOM-элемент категории товара.  
`descriptionElement: HTMLElement` - DOM-элемент с описанием товара.  
`actionButton: HTMLButtonElement` - кнопка действия с товаром.

Сеттеры:  
`category(value: string)` - устанавливает название категории и соответствующий ей CSS-класс.  
`image(value: string)` - устанавливает изображение товара.  
`description(value: string)` - устанавливает описание товара.  
`buttonText(value: string)` - устанавливает текст кнопки действия.  
`buttonDisabled(value: boolean)` - устанавливает состояние доступности кнопки.

Обработчики:  
`onClick` - вызывается при нажатии на кнопку действия.

#### Класс CardBasket

Класс карточки товара в корзине. Наследуется от класса `Card`. Отвечает за отображение порядкового номера товара и вызывает переданный обработчик при нажатии на кнопку удаления.

Данные:  
`ICardBasket` - тип данных карточки товара в корзине, содержащий базовые данные `ICard` и поле `index` с порядковым номером товара в корзине.

Конструктор:  
`constructor(container: HTMLElement, actions: ICardBasketActions)` - принимает корневой DOM-элемент карточки и объект с обработчиком удаления товара.

Поля:  
`indexElement: HTMLElement` - DOM-элемент с порядковым номером товара в корзине.  
`deleteButton: HTMLButtonElement` - кнопка удаления товара из корзины.

Сеттеры:  
`index(value: number)` - устанавливает порядковый номер товара в корзине.

Обработчики:  
`onDelete` - вызывается при нажатии на кнопку удаления товара.

Данные:

Конструктор:

`checkoutButton: HTMLButtonElement` - кнопка оформления заказа.  
`priceElement: HTMLElement` - DOM-элемент общей стоимости товаров.

Сеттеры:  
`items(value: HTMLElement[])` - заменяет содержимое списка переданными DOM-элементами карточек товаров.  
`total(value: number)` - устанавливает общую стоимость товаров в корзине.  
`buttonDisabled(value: boolean)` - устанавливает состояние доступности кнопки оформления заказа.  

События:

`content(content: HTMLElement)` - заменяет содержимое модального окна переданным DOM-элементом.

Класс не генерирует событий.

#### Класс Form

Базовый класс для компонентов форм. Отвечает за отображение общего состояния формы, ошибок валидации и генерирует событие при изменении полей формы.

Данные:  
`IForm` - тип данных формы, содержащий поля `valid` и `errors`.

Конструктор:  
`constructor(events: IEvents, container: HTMLFormElement)` - принимает брокер событий и корневой DOM-элемент формы.

Поля:  
`events: IEvents` - брокер событий, используемый для генерации событий.  
`submitButton: HTMLButtonElement` - кнопка отправки формы.  
`errorsElement: HTMLElement` - DOM-элемент для отображения ошибок валидации.

Сеттеры:  
`valid(value: boolean)` - устанавливает состояние доступности кнопки отправки формы.  
`errors(value: string)` - устанавливает текст ошибки валидации.

События:  
`form:change` - генерируется при изменении значения поля формы.

#### Класс Order

Класс формы первого этапа оформления заказа. Наследуется от класса `Form`. Отвечает за отображение адреса доставки, выбранного способа оплаты и генерирует событие при отправке формы.

Данные:  
`IOrderForm` - тип данных формы оформления заказа, содержащий базовые данные `IForm`, а также поля `address` и `payment` из `IBuyer`.

Конструктор:  
`constructor(events: IEvents, container: HTMLFormElement)` - принимает брокер событий и корневой DOM-элемент формы оформления заказа.

Поля:  
`paymentButtons: HTMLButtonElement[]` - кнопки выбора способа оплаты.  
`addressInput: HTMLInputElement` - поле ввода адреса доставки.

Сеттеры:  
`address(value: string)` - устанавливает значение поля адреса доставки.  
`payment(value: TPayment | '')` - устанавливает визуальное состояние выбранного способа оплаты.

События:  
`form:change` - генерируется при выборе способа оплаты.  
`order:submit` - генерируется при отправке формы оформления заказа.

#### Класс Contacts

Класс формы второго этапа оформления заказа. Наследуется от класса `Form`. Отвечает за отображение электронной почты и телефона покупателя и генерирует событие при отправке формы.

Данные:  
`IContactsForm` - тип данных контактной формы, содержащий базовые данные `IForm`, а также поля `email` и `phone` из `IBuyer`.

Конструктор:  
`constructor(events: IEvents, container: HTMLFormElement)` - принимает брокер событий и корневой DOM-элемент контактной формы.

Поля:  
`emailInput: HTMLInputElement` - поле ввода электронной почты.  
`phoneInput: HTMLInputElement` - поле ввода телефона.

Сеттеры:  
`email(value: string)` - устанавливает значение поля электронной почты.  
`phone(value: string)` - устанавливает значение поля телефона.

События:  
`contacts:submit` - генерируется при отправке контактной формы.

#### Класс Success

Класс отвечает за отображение результата успешного оформления заказа и генерирует событие при нажатии на кнопку возврата к покупкам.

Данные:  
`ISuccess` - тип данных результата оформления заказа, содержащий поле `total` из `IOrderResult`.

Конструктор:  
`constructor(events: IEvents, container: HTMLElement)` - принимает брокер событий и корневой DOM-элемент результата оформления заказа.

Поля:  
`events: IEvents` - брокер событий, используемый для генерации событий.  
`descriptionElement: HTMLElement` - DOM-элемент для отображения итоговой стоимости заказа.  
`closeButton: HTMLButtonElement` - кнопка возврата к покупкам.

Сеттеры:  
`total(value: number)` - устанавливает итоговую стоимость оформленного заказа.

События:  
`success:close` - генерируется при нажатии на кнопку возврата к покупкам.

### События приложения

`catalog:changed` - изменился список товаров каталога.  
`preview:changed` - изменился товар, выбранный для подробного отображения.  
`basket:changed` - изменилось содержимое корзины.  
`buyer:changed` - изменились данные покупателя.  
`basket:open` - пользователь нажал на кнопку открытия корзины в шапке сайта.  
`order:open` - пользователь нажал на кнопку оформления заказа в корзине.  
`form:change` - пользователь изменил значение поля формы или выбрал способ оплаты.  
`order:submit` - пользователь отправил первый этап формы оформления заказа.  
`contacts:submit` - пользователь отправил второй этап формы оформления заказа.  
`success:close` - пользователь нажал на кнопку возврата к покупкам после успешного оформления заказа.  
`product:select` - пользователь выбрал карточку товара для подробного просмотра.  
`product:action` - пользователь нажал кнопку действия с товаром в карточке подробного просмотра. 
`basket:remove` - пользователь нажал кнопку удаления товара непосредственно в корзине.  

### Презентер

Презентер отвечает за основную логику приложения и обеспечивает взаимодействие между моделями данных и компонентами представления посредством событий.

В приложении используется один презентер, реализованный в основном файле `main.ts`, так как приложение состоит из одной страницы.

Презентер подписывается на события моделей и представлений, обрабатывает пользовательские действия, вызывает необходимые методы моделей и обновляет компоненты представления при получении событий об изменении данных, а также при обработке событий открытия модальных окон.
